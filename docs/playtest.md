# 真机试玩清单

给你和朋友第一次带去跑团前用。每项打 ✓ 或记下问题；应用内也可以随时在「日志 → 记一笔反馈」里记，
团后在「设置 → 数据 → 导出试玩反馈」统一导出发给开发者。

## 安装与数据
- [ ] 能打开站点；iPhone 顶部出现「装到主屏幕」提示
- [ ] 添加到主屏幕后从图标打开，是全屏、没有浏览器地址栏
- [ ] 开飞行模式再打开，角色都在，能记伤害
- [ ] 设置 → 数据：显示「已防止被系统清理」（装到主屏后一般会变成这个）
- [ ] 备份全部 → 能下载文件；在另一台设备「从备份恢复 → 合并」能看到角色

## 车卡
- [ ] 新手：空角色库里点一个示例角色，直接进入角色卡
- [ ] 新建 3 级角色，走完所有步骤，没有卡住或看不懂的地方
- [ ] 朋友发来的角色文件能导入

## 跑团中
- [ ] 点生命值记伤害 / 治疗；专注中受伤会弹专注检定
- [ ] 开始战斗 → 用动作 / 附赠 / 反应后对应芯片变灰；「新回合」重置
- [ ] 攻击、施法、掷伤害；实体骰模式下输入自己掷的点数
- [ ] 法术位、职业资源扣减正确；短休 / 长休恢复正确
- [ ] 捡到药水 → 「自己用」→ 回血；换护甲后 AC 变化
- [ ] 点错了能撤销（顶部撤销，或日志里单条撤销）
- [ ] 团后在角色卡上「升级」

## 手感
- [ ] 按钮够大，单手能点到；没有误触
- [ ] 屏幕边缘的系统返回手势和应用操作不冲突
- [ ] 刘海 / 底部横条没有挡住内容
- [ ] 字号在桌上暗光环境里看得清
- [ ] 连续操作不卡顿（尤其是打开动作详情、切换标签）

## 画面与反馈（M6b）
- [ ] 车卡选职业 / 种族 / 背景、选子职时能看到插画，首次加载不卡
- [ ] 断网后已看过的插画仍在；没看过的显示原来的图标，不是破图
- [ ] 设定页上传头像，或从默认头像中选一个；角色库和角色卡都显示
- [ ] 掷骰时骰子翻滚约半秒再出结果；点结果条可跳过；暴击 / 大失败有明显效果
- [ ] 受伤时生命值闪红、轻微晃动；降到 0 出现「倒地！」；专注失败有紫色提示
- [ ] 角色卡上左右滑动切换标签；从屏幕边缘滑动仍是系统返回，不会误切
- [ ] 设置里打开「音效」后掷骰、暴击、回血有声音；默认无声
- [ ] 系统开启「减少动态效果」后，翻滚和晃动都不出现

## 角色形象与配图（M7a）
- [ ] 设置 → AI 生图：新建连接，填 https 地址和自己的密钥，点「连接」后选模型；再建一个连接，切换使用中的连接
- [ ] 角色卡点左上角头像 → AI 生成 →「从角色填充」→ 生成；等待时关掉面板，生成好后点提示里的「查看」
- [ ] 加一张自己的照片作参考图再生成，看人物是否像
- [ ] 裁剪头像后：角色卡页头、角色库卡片背景都换成新立绘
- [ ] 工坊新建法术 / 职业 / 种族时配一张图；车卡展示区、角色卡动作详情里能看到
- [ ] 导出备份文件，搜索确认里面没有密钥

## 音效（M7b）
- [ ] 设置里打开「音效」
- [ ] 创造工坊 → 提示音：把「大成功」换成一段录音（试试手机录音），截取后试听；掷出 20 时听到它；「恢复默认」后变回合成音
- [ ] 工坊给法术 / 物品配音效，或在职业特性的动作里加「使用时的音效」；角色卡上使用或掷攻击时播放
- [ ] 换一台设备导入备份，替换的提示音还在
